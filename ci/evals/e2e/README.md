# E2E acceptance implementation

This package is called by the unified evaluator. Run it through [evals.sh](../readme.md): `run --suite e2e`, or `run --suite full` to include all independent tasks.

The supplied definitions/ are reference implementations. They are used by offline checks and explicit reference acceptance; agent-generated runs receive public contracts and requirements instead. See [E2E coverage](../docs/E2E_COVERAGE.md) for scenario details.

# Evaluation command reference

Start with the [run guide](../readme.md) to choose a preset. All examples are run
from the repository root through `sh ci/evals/evals.sh`. Relative paths resolve
from `ci/evals/`. Use `COMMAND --help` for the installed option list.

## Commands and effects

| Command | Purpose | Model calls | Real tenant calls |
|---|---|---|---|
| `help` | Show commands and presets | No | No |
| `check` | Validate all task references and E2E reference lint/bindings/negative checks | No | No |
| `list` | Preview selected tasks and mandatory E2E | No | No |
| `run` | Solve, grade, execute required runtime checks and clean up | Agent/grader sessions; reference E2E uses none | Engine/E2E selections |
| `report` | Read results, compare baselines, export Markdown | No | No |
| `grade` | Grade one saved task's evidence | Semantic criteria only | No new engine execution |
| `calibrate` | Check semantic graders against correct/broken reference evidence | Yes | No |
| `calibrate-engine` | Verify task reference outputs on the engine | No | Yes |
| `calibrate-engine-mutants` | Check task engine assertions reject broken candidates | No | Yes |
| `review` | Regrade saved task work; preserve original E2E evidence | Semantic criteria only | Task engine checks where required |
| `refresh-fixtures` | Replay task reference API actions into a proposed bank | No | No |
| `mine` | Inventory source content | No | No |
| `cleanup` | Remove recorded engine/E2E resources, including older live journals | No | Yes |
| `schema` | Generate the task bank schema | No | No |

Model runs and calibration require approval in this collaboration. Commands below
are individual alternatives, not a script to execute in sequence. Reference E2E
uses no model tokens but still deploys, executes and removes tenant resources.

## Help and offline verification

```sh
sh ci/evals/evals.sh help
sh ci/evals/evals.sh run --help
sh ci/evals/evals.sh check
sh ci/evals/evals.sh check --source ~/Git/autopi-content
sh ci/evals/evals.sh list --suite smoketest
sh ci/evals/evals.sh list --suite minimal
sh ci/evals/evals.sh list --suite full
sh ci/evals/evals.sh list --suite e2e
```

`check` runs the complete offline checks, independent of the default smoketest
selection. It validates infrastructure and references; it does not measure a model's
ability to use the skills. Engine/semantic calibration are separate live activities.

## Run: complete presets

```sh
# Configured Claude candidate and grader models.
sh ci/evals/evals.sh run --suite smoketest --agent claude --run smoke-claude-01
sh ci/evals/evals.sh run --suite minimal --agent claude --run minimal-claude-01
sh ci/evals/evals.sh run --suite full --agent claude --run full-claude-01

# Configured Codex candidate and grader models.
sh ci/evals/evals.sh run --suite smoketest --agent codex --run smoke-codex-01
sh ci/evals/evals.sh run --suite minimal --agent codex --run minimal-codex-01
sh ci/evals/evals.sh run --suite full --agent codex --run full-codex-01

# E2E alone: generated by the selected agent, deterministic runtime grading.
sh ci/evals/evals.sh run --suite e2e --agent claude --model sonnet --run e2e-claude-01
sh ci/evals/evals.sh run --suite e2e --agent codex --run e2e-codex-01

# E2E reference acceptance; no host login or model sessions.
sh ci/evals/evals.sh run --suite e2e --e2e-mode reference --run e2e-reference-01
```

Full always runs 160 tasks plus agent-generated E2E. Standalone E2E runs no task-bank
cases. `--runs 2` repeats the complete selected campaign twice, including E2E. Default
is one generation, no repair, one worker. E2E generations and repairs deploy separate
resource sets and execute sequentially. Ordinary task graders do not grade each E2E
assertion. Candidate model/effort overrides also apply to the E2E generation; grader
settings apply to independent tasks only.

## Run: models, budgets, filters and comparison

```sh
# Cheaper Claude candidate, stronger separate grader.
sh ci/evals/evals.sh run --suite smoketest --agent claude \
  --model haiku --grader-model sonnet --run smoke-cheaper-01

# Independent hosts; use a Codex model your provider supports.
sh ci/evals/evals.sh run --suite minimal --agent codex --grader claude \
  --model CODEX_MODEL_ID --effort low --grader-model sonnet --run mixed-01

# Bounded full campaign; inspect partial results if the reservation limit is reached.
sh ci/evals/evals.sh run --suite full --agent claude --model sonnet --grader-model sonnet \
  --budget-usd 200 --case-budget-usd 1 --grader-budget-usd 0.25 \
  --e2e-budget-usd 5 --e2e-timeout 45m --runs 1 --repair 0 --parallel 1 --run full-bounded-01

# Four local smoketest tasks, with no real-tenant calls.
sh ci/evals/evals.sh run --suite smoketest --tier local --agent codex --run local-smoke-01

# One selected task; case, primary-skill and tier filters intersect.
sh ci/evals/evals.sh run --suite smoketest --case proposal-scope \
  --agent codex --run one-case-01
sh ci/evals/evals.sh run --suite minimal --skill automation-pilot-cli \
  --tier local --agent claude --run cli-local-01

# Explicit no-skill comparison, with the same CLI and public contracts.
sh ci/evals/evals.sh run --suite smoketest --agent codex \
  --ablation without-skills --run smoke-without-skills-01

# Preserve first failures and score one repair separately.
sh ci/evals/evals.sh run --suite e2e --agent claude \
  --model sonnet --repair 1 --e2e-budget-usd 10 --run e2e-repair-01
```

Full and standalone E2E reject `--skill`, `--tier` and `--case`. For deliberately
filtered bank-wide tasks, the legacy `--suite regression` selection remains bank-only.
The other compatibility names are pilot=minimal, smoke=40 tasks, all/regression=160
tasks, release=160 tasks with three default generations. They do not include E2E;
use full for the complete unified campaign.

Unsupported model IDs fail rather than being replaced. Claude aliases and Codex
IDs depend on the configured provider. See the [model cookbook](models.md) for all
candidate/grader pairings. Codex USD reservations are not enforceable billing caps.

## Reports

```sh
sh ci/evals/evals.sh report --run runs/full-bounded-01
sh ci/evals/evals.sh report --run runs/full-bounded-01 --out runs/full-bounded-01/summary.md
sh ci/evals/evals.sh report --run runs/new-baseline --compare runs/old-baseline/report.json
```

Reports use task results and a separate E2E section, with original verdicts, repairs,
usage/cost, per-assertion evidence and cleanup errors. Markdown export needs a fresh
file. The report command reads saved data and never runs a grader or contacts a tenant.
Baseline comparison requires compatible host/model/configuration, task bank/grading
protocol and E2E requirements/acceptance implementation.

## Grade and calibration

```sh
# Model grading of one captured task; does not deploy it again.
sh ci/evals/evals.sh grade --case local-authoring \
  --evidence runs/smoke-codex-01/local-authoring/generation-1/evidence.json \
  --agent codex --grader codex --grader-model CODEX_GRADER_MODEL_ID

# Semantic-grader calibration, including correct references and deliberate defects.
sh ci/evals/evals.sh calibrate --suite smoketest --agent claude \
  --grader claude --grader-model sonnet --out runs/calibration-sonnet-01.json

# Resume only matching successful calibration judgments; changed protocol/config refuses reuse.
sh ci/evals/evals.sh calibrate --suite smoketest --agent claude \
  --grader claude --grader-model sonnet --resume runs/calibration-sonnet-01.json \
  --out runs/calibration-sonnet-02.json

# Real-engine reference and broken-candidate checks for independent tasks.
sh ci/evals/evals.sh calibrate-engine --suite minimal --out runs/engine-calibration-01
sh ci/evals/evals.sh calibrate-engine-mutants --suite minimal --out runs/engine-mutants-01
```

These calibration commands operate on independent task cases, not the complete E2E
workflow. Use E2E reference mode to validate its complete acceptance path. A smaller
grader configuration needs its own calibration before trusting its semantic scores.
Source/configuration fingerprints prevent silent reuse after protocol changes.

## Review captured work

```sh
sh ci/evals/evals.sh review --run runs/smoke-codex-01 --out runs/smoke-reviewed-01 \
  --agent codex --grader claude --grader-model sonnet --parallel 1
```

Review requires a fresh output directory and unchanged public task prompts/files.
It regrades independent tasks without new candidate sessions; applicable task engine
checks may execute again. Original E2E scores/evidence are retained, not rerun. A
review cannot turn an incomplete candidate session into a successful generation.
Recorded costs include reused sessions; do not add the original total a second time.

## Fixture refresh, mining and schema

```sh
sh ci/evals/evals.sh refresh-fixtures --out cases/proposed-bank.json
sh ci/evals/evals.sh mine --source ~/Git/autopi-content --out runs/source-inventory.json
sh ci/evals/evals.sh schema --out cases/bank.schema.json
```

Review proposed reference changes before replacing the bank. These outputs can
replace files; choose fresh names to preserve previous work. Mining inventories
sources; it does not automatically create or certify new cases.

## Cleanup

```sh
# A task+E2E campaign, or standalone E2E.
sh ci/evals/evals.sh cleanup --run runs/full-codex-01
sh ci/evals/evals.sh cleanup --run runs/e2e-codex-01

# An older migrated live journal.
sh ci/evals/evals.sh cleanup --run runs/legacy-e2e/OLD_RUN_ID
```

Cleanup verifies the current environment's tenant against the recorded identity.
Recovery uses journaled resource IDs and fixed harness metadata, so missing candidate
files do not prevent cleanup. A recovered runner is cleanup-only. It does not start
agents or re-deploy, and reports
unresolved writes instead of guessing. Automatic E2E cleanup has five minutes;
engine cleanup has three minutes. Keep private journals until cleanup is verified.

## Every option

Options are shared by the dispatcher; applicability is described above and by the
command's validation. Paths are relative to ci/evals unless absolute.

| Option | Default | Purpose |
|---|---|---|
| `--bank` | cases/bank.json | versioned evaluator-only bank |
| `--suite` | smoketest | smoketest (12), minimal (20), full (160 + E2E), e2e; legacy pilot, smoke, regression, release, all |
| `--skill` | configured/empty | comma-separated primary skill filter |
| `--tier` | configured/empty | comma-separated tier filter |
| `--source` | configured/empty | autopi-content checkout for mining/source verification |
| `--repository` | ../.. | skills repository |
| `--out` | configured/empty | output path; report writes a fresh Markdown summary without model calls |
| `--run` | configured/empty | fresh run ID for run; existing report directory for report/cleanup |
| `--case` | configured/empty | single case ID for run or grade |
| `--evidence` | configured/empty | private captured evidence JSON for grade |
| `--model` | configured/empty | agent model override; empty uses the CLI default; choose a smaller supported model for cheaper runs |
| `--grader-model` | configured/empty | semantic grader model override; empty uses the grader CLI default |
| `--agent` | auto | auto (prefer installed Claude), claude, or codex |
| `--agent-bin` | configured/empty | optional executable path for the selected agent |
| `--grader` | configured/empty | claude or codex; empty uses the agent host |
| `--grader-bin` | configured/empty | optional grader executable path |
| `--effort` | configured/empty | agent reasoning effort override; empty uses the CLI default |
| `--grader-effort` | configured/empty | grader reasoning effort override |
| `--isolation` | native | native CLI sandbox/permissions, or Linux bubblewrap filesystem isolation |
| `--ablation` | with-skills | with-skills or without-skills (same CLI in both) |
| `--runs` | 1 | independent fresh generations; release defaults to three |
| `--parallel` | 1 | independent concurrent case/grader sessions (1-8); engine mutations remain sequential |
| `--repair` | 0 | optional bounded repair round (0 or 1); first results remain unchanged |
| `--budget-usd` | 0 | run reservation limit (0 disables); Codex does not report USD cost |
| `--case-budget-usd` | 1 | reserved ceiling per agent session |
| `--grader-budget-usd` | 0.25 | reserved ceiling per semantic-grade session |
| `--tenant` | configured/empty | optional identity assertion; engine tenant is resolved from AUTOMATION_PILOT_HOSTNAME and AUTOMATION_PILOT_TOKEN |
| `--compare` | configured/empty | baseline report.json path |
| `--e2e-mode` | agent | agent-generated E2E, or reference (standalone e2e only; no model sessions) |
| `--e2e-budget-usd` | 5 | reserved ceiling per E2E generation/repair session |
| `--e2e-timeout` | 45m | total E2E generation and acceptance deadline; cleanup has a separate bound |
| `--resume` | configured/empty | calibrate only: reuse successful matching challenges from an existing calibration report |
